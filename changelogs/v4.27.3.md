## [4.27.3] - 2026-08-18

### Added

- Added a Volcengine Ark OpenAI-compatible provider preset with the Beijing API endpoint and DeepSeek V4 Flash GA as the default model. The model field also accepts the Doubao Seed 2.0 series and Ark endpoint IDs.

### Fixed

- Added a safe fallback for proactive cron jobs that finish with an assistant response without calling `send_message_to_user`, while avoiding duplicate delivery when the tool already sent a message.

### Maintenance

- Retained OpenCode Go and OpenCode Zen provider support.
